# Forms of Academe
Repository of LinkedArt JSON metadata files related to the *Forms of Academe* project.

## Forthcoming
Once the *[Forms of Academe](https://digitalcollections.trentu.ca/web/forms-of-academe/)* leaves its beta testing phase, this repository will be the version control for related metadata files using *[Linked Art](https://linked.art/)*. Major versions will also be regularly deposited in *[Borealis: The Canadian Dataverse Repository](https://borealisdata.ca/dataverse/trent)*.
